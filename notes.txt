Για να αποκτήσεις άμεση πρόσβαση στη βάση σου και να βεβαιωθείς ότι όλα είναι συνδεδεμένα σωστά, ακολούθησε αυτά τα 3 βασικά βήματα:

Το MongoDB Atlas μπλοκάρει από προεπιλογή όλες τις συνδέσεις
Στο MongoDB Atlas, πήγαινε στο αριστερό μενού στην ενότητα Security -> Network Access.
Πάτα Add IP Address.
Επίλεξε είτε Add Current IP Address (μόνο για το δικό σου δίκτυο) είτε Allow Access from Anywhere (0.0.0.0/0) για να μπορείς να συνδέεσαι από παντού χωρίς προβλήματα κατά το development.
Πάτα Confirm.

το όνομα της βάσης το ορίζουμε εμείς μέσα από το url,
και αν δεν υπάρχει ήδη δημιουργείται μέσα από το url
